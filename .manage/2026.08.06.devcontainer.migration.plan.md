# Plan of Action — Gitpod Removal & Dev Container Migration

> Tracks GitHub issue [#3](https://github.com/xingh/arkitype/issues/3): *update / remove gitpod related things*.
>
> Goal: make Arkitype (1) a container anyone can open on their desktop, (2) a getting-started environment for running this repo's prompts/skills with Claude Code, (3) a Claude Code plugin library in its own right, and (4) usable inside a GitHub runner.

---

## Context

Gitpod changed its product model and no longer serves the workspace-from-`.gitpod.yml` flow this repo relied on. VS Code Dev Containers is now the portable standard: the same `devcontainer.json` works on desktop (VS Code + Docker), in GitHub Codespaces, and in CI via `devcontainers/ci`.

What Gitpod was doing for us, per the old files:

| Old Gitpod artifact | What it did | Disposition |
|---|---|---|
| `.gitpod.yml` | Installed Claude Code CLI on init, listed VS Code extensions, opened ports 25565/8080 | Replaced by `.devcontainer/devcontainer.json` (`postCreateCommand`, `customizations.vscode.extensions`); ports dropped — nothing in this repo serves them |
| `.gitpod.Dockerfile` | `gitpod/workspace-full` + Python, Node 20, TypeScript, .NET 8, Scala, sbt, Groovy | Replaced by `javascript-node:20` base image + Python feature. .NET/Scala/Groovy dropped — no code in this repo uses them; re-add as devcontainer features if ever needed |

## Decisions & open questions

1. **Toolchain slimming**: the Gitpod image carried .NET, Scala, sbt, and Groovy with zero usage in-repo. Dropped. If a future Arkitype target needs them, they return as one-line devcontainer features.
2. **Codespaces**: comes for free with `devcontainer.json` — no extra work, worth mentioning in README.
3. **Auth in containers**: desktop users authenticate Claude Code interactively on first run; runners use `ANTHROPIC_API_KEY`. Never bake credentials into the image.
4. **Open question**: should the plugin marketplace live in this repo (arkitype = library) or a dedicated `xingh/arkitype-plugins` repo (arkitype = methodology, plugins = distribution)? Default: keep it here until it outgrows the repo.
